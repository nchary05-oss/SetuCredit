The Solution03 / 09

A consent-first bridge from records to credit.

SetuCredit is a middleware orchestration layer that turns consented, non-financial records into a real-time readiness score — and a lender-ready package.

Voice onboarding
Bhashini speech in 12+ Indian dialects, on a 3G-friendly PWA.
Identity
Aadhaar OTP with DigiLocker verification — no paperwork.
Consent first
Explicit, time-bound, revocable consent via Account Aggregator.
Parallel ingestion
ULI and AA rails fan out together — land, utility, BBPS, banking.
Instant outcome
Readiness Index → lender webhook → UPI/IMPS disbursal.
Outcome
First utterance to credited funds, in under two minutes.

Heuristic v1 today; XGBoost drops in behind the same interface as pilot data accumulates.

Consent-first by construction
Pass-through memory
Borrower non-financial data is never persisted — not even as derived features. Postgres keeps only audit events, consent records and outcomes.
Consent enforced in code
Every DPI pull requires an active, purpose-scoped consent. Missing or revoked consent is an HTTP 403 — not a policy in a PDF.
Encrypted end to end
TLS 1.3 in transit; AES-256 for every stored audit log and ledger entry.
Explainable outcomes
Every score is traceable to specific consented records — no black-box rejections for a first-time borrower.
DPDP Act aligned
Data minimisation, purpose limitation and revocation are implementation choices here — not compliance afterthoughts.
